What happened?

BSMS Web originally went down after a message in BSMS Chat triggered the profanity checker. The checker was not configured correctly and produced data that the server could not understand.

This caused the server to crash unexpectedly, taking down BSMS Chat, Accounts, and the update system at the same time.

Current situation: Most of BSMS Web has now been restored. Accounts and BSMS Chat are still unavailable while we finish fixing the remaining problems and improve the way the system handles unexpected data and edge cases.
